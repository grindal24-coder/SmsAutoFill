# SMS AutoFill Demo (фоновый режим, 2 дизайна попапа)

Android-проект на Kotlin: приложение можно **полностью закрыть**, и при
приходе SMS с кодом всё равно всплывёт попап с предложением вставить код
— поверх любого другого приложения. Google Play Services не используются.

## Два дизайна попапа

**Дизайн 1 — диалог (Activity).** Обычный `AlertDialog` внутри отдельного
экрана, запускается прямо из `SmsReceiver.onReceive()`. Это
задокументированное исключение из ограничений Android на запуск экранов
из фона, но на некоторых устройствах/версиях Android система всё равно
может это блокировать, если в этот момент открыто другое приложение —
попап тогда появится только когда вы сами откроете это приложение.

**Дизайн 2 — оверлей (рекомендуется).** Настоящее оверлей-окно через
`WindowManager`, не Activity. Требует отдельное разрешение "Отображать
поверх других приложений" (`SYSTEM_ALERT_WINDOW`), но НЕ подпадает под
ограничения на запуск активностей из фона — поэтому появляется поверх
любого приложения (в том числе Y) надёжно, независимо от того, что сейчас
открыто.

Выбор дизайна — в приложении, через переключатель. Кнопка "Показать
пример выбранного дизайна" показывает попап с тестовым кодом 12345, чтобы
сравнить оба варианта визуально, не дожидаясь реальной SMS.

## Как собрать APK на GitHub

1. Замените содержимое репозитория (кроме `.git`) содержимым этого
   архива, чтобы не оставалось старых файлов из прошлых версий.
2. ```bash
   git add -A
   git commit -m "Add overlay popup design"
   git push
   ```
3. Вкладка **Actions** → сборка запустится сама → скачайте APK из
   **Artifacts**.

## После установки на телефон

1. Откройте приложение, выдайте по очереди:
   - "Разрешить чтение SMS"
   - "Снять ограничения батареи"
   - "Разрешить показ поверх приложений" (откроется отдельный экран
     настроек — включите тумблер для этого приложения)
2. На Xiaomi/Huawei/Honor и похожих прошивках дополнительно разрешите
   "Автозапуск" в настройках приложения.
3. Выберите дизайн 2 (оверлей) — он надёжнее для случая "код пришёл, пока
   открыто другое приложение".
4. Закройте приложение — при приходе SMS с кодом попап появится сам.

## Ограничение, о котором важно знать

Ни один из дизайнов не может **автоматически напечатать** код в поле
стороннего приложения (Android не даёт одному приложению трогать UI
другого) — кнопка "Вставить" копирует код в буфер обмена, вставить нужно
вручную одним тапом. Полностью автоматическая вставка без единого нажатия
возможна только через Accessibility Service — отдельная, более тяжёлая
доработка с ручной активацией разрешения в настройках.
